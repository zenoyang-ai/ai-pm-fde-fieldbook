Replay-only · 不调用模型Local Live recording

AI PM Studio｜五角色 Agent 工作台

把产品方案形成过程做成可查看的五角色交接、返工与导出链路；公开入口为流程回放，不暗示在线模型调用或多人生产系统。

Primary signal产品流程、阶段编排与人工 Gate
Public proof公开 Replay + 本地全链路录屏
Boundary公开交付为 Replay-only，不是公网生产系统

Problem

AI 产品从想法走向原型时，需求、研究和产品方案容易混在一次对话里，产物难以分步审阅与修改。

Decision

独立定义需求、研究、产品、原型和评审五角色；前序产物传递到下一阶段，并在入口和评审处保留人工 Gate。

Artifact

本地可运行工作台、结构化阶段产物、沙箱 HTML 原型、运行记录与导出链路。

Evidence

公开 Replay 可查看五角色交接、返工与导出；本地记录曾跑通模型 API 与 Hermes Web 检索全链路。

Verified

  • 五角色阶段链路与结构化产物。
  • 公开入口为固化流程回放。
  • 核心流程与导出路径已验收。

Not claimed

  • 不主张公网多人生产运行。
  • 不主张公开入口实时调用模型。
  • 不主张真实客户、SLA 或商业结果。

02 评测闭环 · 自动化工作流
Reachable demo · 可视化看板External workflow page

自动化质检｜AI 工作流与可视化看板

把自动化质检链路做成可浏览的流程看板，并保留 Coze 工作流开发页作为实现侧证据；当前仅呈现演示与开发入口，不外推为生产部署。

Primary signal规则拆解、质量判断与自动化交付
Public proof演示看板 + Coze 工作流开发页
Boundary不外推为生产部署、用户规模或 SLA

Problem

RL 数据存在图文不一致、步骤判定分歧等问题，质检规则和判断链需要从人工 SOP 变成可复查的工作流。

Decision

确定性字段交给代码规则，截图状态交给 VLM，任务目标与轨迹的一致性由 LLM 辅助判断，最终保留完整人工复核。

Ownership

直接贡献是规则拆解、九节点工作流搭建、Prompt/字段映射和人机分歧样本迭代；模型训练与项目整体结果由团队共同完成。

Result

交付 2000+ 条 RL 训练数据；内部抽检合格率 97.5%，机器预检与人工最终判定一致率 90%，单人日均质检产能 25 条提升至 37 条，仍保留人工复核。

Verified

  • 存在可访问演示看板和工作流页。
  • 九节点质检链路与人工复核边界有明确素材。
  • 指标范围来自项目工作记录，不是模型准确率。

Not claimed

  • 不主张自动化替代人工复核。
  • 不主张客户现场、生产监控或 SLA。
  • 不主张 97.5% 是线上长期质量或模型能力。

倪海厦知识图谱｜AI 问答助手

Public proofWeb 主站 + 小程序形态 + GitHub Pages
Boundary146/146 是 v5.5.x 本地测试；v5.3.0 是小程序正式版

Problem

天纪、人纪资料分散，学习后难以快速定位、串联和复习，需要同时解决知识导航与问答入口的问题。

Decision

Artifact

Result

形成 69 个可视化节点、338 条节点关联，校验 0 条悬空关系；审计 231 项资料，生成 4852 个检索块。

Verified

  • 69 个可视化节点、338 条关系、0 条悬空关系。
  • v5.5.x 本地自动化回归 146/146。

Not claimed

  • 不把本地回归写成线上准确率。

04 SFT / LoRA · 对话助手
External chat · DifyOffline evidence · 55/55

阿德勒对话助手｜SFT-LoRA 微调

围绕亲子教育、职场发展、自我成长、亲密关系和人生意义五类场景，把阿德勒理论转成角色规则、回答结构和禁用语，再用 SFT-LoRA、离线评测与 Dify 原型验证闭环。

Primary signal对话产品定义、SFT-LoRA 与评测
Public proof外部聊天入口 + 训练 / 评测素材
Boundary项目内自建、单人离线、仅作目标场景方向性验证

Problem

基线模型在特定心理学对话中存在理论堆砌、说教式表达和角色不稳定，需要把抽象原则变成可执行质量标准。

Decision

以目的论、课题分离和横向关系定义角色规则、回答结构与禁用语；选择 Doubao-1.5-pro-32k 基座完成两轮 SFT-LoRA。

Artifact

500 条对话数据、训练任务、五维评测标准、Badcase 迭代记录与 Dify 对话原型。

Result

项目内自建 55 条离线测试集，微调版本逐题胜出 55/55；这是单人、离线、目标场景的方向性验证，不是泛化准确率。

Verified

  • 500 条对话数据、两轮 SFT-LoRA。
  • 项目内自建 55 条离线评测。
  • 微调模型已接入 Dify 对话小助手。

Not claimed

  • 55/55 不写成广泛准确率或用户满意度。
  • 不作为心理诊断、治疗或危机干预。
  • 外部聊天链接不单独证明训练配置和线上效果。

Working Method / 05

从业务判断到证据交付，用同一条闭环推进。

这个模块不是“技能关键词”，而是招聘者可用来判断你如何工作的过程信号。

01

问题与用户

先确定真实场景、决策对象、成功条件与不做什么。

02

方案与边界

判断 Agent、RAG、工作流或微调是否必要，并明确人工 Gate。

03

原型与交付物

把 PRD、用户流程、原型、Tool/Workflow 结构转成可查看 Artifact。

04

评测与 Badcase

记录基线、样本范围、失败类型、修复动作和复测方式。

05

证据与复盘

区分可访问入口、Replay、离线验证和待补证据，不把方向性结果包装成生产成功。
